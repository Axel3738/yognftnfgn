# /sheet – Fyll i tracking-sheetet för produktens alla ads

> **Innan du frågar användaren något:** fråga dig själv om det finns ett sätt att
> ta reda på svaret som du inte provat än — repo + git-historik, Drive, Notion,
> Meta, Shopify, product sheetet. Fråga bara när svaret kräver ägaren (pris,
> rabatt, target-CPA). Den som kör kan vara helt icke-teknisk: en fråga i taget,
> enkel svenska utan fackord, och ge alltid ett rekommenderat svar att säga ja till.

Argument: `$ARGUMENTS` — produkt-id.
Exempel: `/sheet motorholjet`

Fyll i tracking-sheetet för ALLA ads vi gjort för produkten och leverera en ifylld xlsx-fil.

Mall (innehåller exempel från ett annat brand): https://docs.google.com/spreadsheets/d/1qE_aHF8aD_p5pr7ZuJruKBkVVWBl5wGQdf9oqqvwkh8/edit?usp=sharing

Regler:

- Extremt noggrant — sheetet är grunden vi bygger på i flera år.
- Använd kolumnernas befintliga dropdown-alternativ där de finns. Fria fält (avatarer o.dyl.) får du formulera själv.
- En rad per annons, inklusive gamla batcher. Performance-data från Ads Manager (MagiBorsten `1867947880635861`) — hitta inte på.

## DEFINITION OF DONE

- [ ] Antal rader = antal annonser i kontot för produkten (skriv båda talen)
- [ ] Dropdown-kolumner använder befintliga alternativ
- [ ] Siffror hämtade från Ads Manager
- [ ] XLSX levererad

# Batch 5.1 — försvenskade skördebilder (Bäverbutiken SE)

Slutversioner som ligger i produkterna 2026-08-29. Skörden kom som 6 zippar
från Axels dator (133 MB, ej i repot — för tung). GIF:ar + videor ligger på
butikens CDN (`b5-*.gif` i Files + produktmedia).

**Metoden** (samma som grillöverdraget, se `../grilloverdrag-sv/README.md`):
KIE tar bort utländsk text (9 jobb varav 7 godkända), sharp ritar svensk
vektortext. Underkända KIE-resultat: diskstall-14 (hallucinerad ställning),
magnethylla-02 (suddiga kanter) — användes inte.

**Variantfacit som styrde bildvalen** (kolla ALLTID mot butiken):
sandbild = Röd/Bärnsten (videons blå sand fick INTE bli GIF), veckodosett =
svart (skördens bruna/gröna bilder användes inte), luffarschack = svart/vit
(videons orange brickor fick inte bli GIF), magnetplattor = 46/60 delar
(skördens "48pcs"/"68pcs"-bilder förbjudna), sömnadskit = 104 delar
("111pcs"-bilden förbjuden), mc-väskan har blandade loggofärger i egen
huvudbild (ok). Jetfläkt/arbetslampa säljs UTAN batteri — kit-bilder med
batterier+laddare användes inte; användnings-GIF:ar med kundens batteri är ok.

**Kvar:** kastfånga (saknades helt i skörden — behöver egen skördekörning),
lövblåsare + fotokudde (ej skapade än), NO/DK/FI/UK-butikernas gallerier och
beskrivningar (samma bilder, egna språktexter — sharp-om från originalen).

# Video Ad Briefs – Seatcover (Sätesöverdrag för Åkgräsklippare)

Global rules for ALL video ads in this package. Each ad has its own folder with a self-contained `brief.md` — an editor should be able to work from that file alone. Read this README once before starting.

## Product facts (single source of truth — never improvise)
- Product: Seat cover for riding lawn mowers, 600D Oxford fabric, water-repellent, padded inside, adjustable straps, fits most riding mowers/garden tractors, installs in under 60 seconds without tools.
- Colors: 4 (Grå / Svart / Grön / Ljusgrå).
- **Price: 649 kr. Original price: 811 kr.** These exact numbers everywhere. Never any other price. If a design shows a strikethrough on 811 kr, it must be a REAL strikethrough line — never the word "överstruket" written out (this bug shipped once; it is why one existing image is banned).
- Free shipping in Sweden. Klarna available. 30-day money-back guarantee ("30 dagars nöjd-kund-garanti").
- Landing page: https://baverbutiken.se/products/satesoverdrag-for-akgrasklippare-slittaligt-600d-oxford

## Hard rules
1. **Product visible on screen before second 1** (never later than second 4).
2. **Burned-in Swedish captions on every video.** White text, black outline, bottom third, word-for-word from the script table. This is the single most proven variable in the account (with captions ROAS 2.81, same video without captions ROAS 0.53). Never deliver a caption-free master.
3. Swedish text in ads must be copied **word-for-word** from the "Swedish (use this)" column. Do not re-translate, do not "improve" spelling. Watch Swedish characters å/ä/ö — they must render correctly.
4. Known spelling traps: "sätesöverdrag" (not "sätesövredrag"), "åkgräsklippare", "vadderad", "nöjd-kund-garanti". No English words in on-screen text.
5. Sound design: video must work 100% muted. Voiceover (VO) is a bonus layer, not a carrier.
6. Export: **9:16 (1080×1920) AND 4:5 (1080×1350)** for every ad. Keep captions inside title-safe area for both crops.
7. Naming: use the exact ad name of the folder (e.g. `Seatcover_PD_4_H1`) as the file name of the export. Never reuse or renumber IDs.
8. No fabricated testimonials, no "Verifierad kund", no invented review counts. Proof claims only from real, documented reviews (a separate blocker list states which briefs wait for that).

# 1. Information och åtkomst som behövs

## A. Åtkomst (teknisk)

| # | Vad | Varför | Status |
|---|-----|--------|--------|
| A1 | Shopify-åtkomst till **källbutiken** (admin eller MCP-koppling) | Export av produkter, tema, sidor, policyer | ✅ Bäverbutiken.se är kopplad (läs + skriv via MCP) — bekräfta att det är rätt källa |
| A2 | Shopify-åtkomst till **målbutiken** (om separat butik, inte bara ny marknad i samma) | All uppbyggnad sker där | ⬜ Finns målbutiken? Vem skapar den? |
| A3 | Temaåtkomst (möjlighet att duplicera live-temat och arbeta i kopian) | Temaändringar görs aldrig direkt i publicerat tema | ⬜ (MCP tillåter temafilsskrivning endast i opublicerade teman — det räcker) |
| A4 | Domän för nya marknaden (befintlig eller ska köpas) | Domän-, e-post- och marknadskonfiguration | ⬜ Ditt ansvar vid köp |
| A5 | Tillgång till bildkälla: original-/leverantörsbilder eller egna bilder | Produktbilder, banners | ⬜ |
| A6 | Ev. appar i källbutiken (t.ex. Kaching Bundles som redan finns) — ska motsvarande installeras i målbutiken? | Bundles, recensioner, översättning | ⬜ Appinstallation = ditt godkännande |
| A7 | E-postadress för kundsupport på nya marknaden | Policyer, kontaktsida, e-postmallar | ⬜ |

## B. Information (beslut)

| # | Vad | Exempel på svar som behövs |
|---|-----|---------------------------|
| B1 | Källbutik | "Bäverbutiken.se, hela sortimentet" eller delmängd |
| B2 | Målmarknad + språk | t.ex. Norge/norska (bokmål), Danmark/danska, Finland/finska+svenska, DACH/tyska |
| B3 | Setup-modell | (a) ny marknad i samma Shopify-butik (Markets + översättning), eller (b) helt separat butik |
| B4 | Produktsortiment | Alla 130 aktiva? Bara bästsäljare? Exkludera vissa kategorier? |
| B5 | Valuta + prisstrategi | t.ex. NOK, omräkning ×-faktor + psykologisk avrundning (…9 kr), eller manuell prislista |
| B6 | Varumärkesnamn på nya marknaden | Samma namn? Översatt? Nytt namn? Finns domän + ev. varumärkesskydd kollat? |
| B7 | Visuell riktning | Behåll nuvarande tema/utseende, eller ny logotyp/färger/typografi? |
| B8 | Leveransländer + leverantörsupplägg | Vilka länder skickas till? Samma leverantör (Temu-sortiment) — vilka leveranstider ska utlovas? |
| B9 | Returupplägg | Returadress i målmarknaden? Vem betalar retur? Ångerrätt (EU 14 dagar minimum) |
| B10 | Rättigheter till material | Vilka bilder/texter/logotyper får återanvändas? Källa och licens per typ |
| B11 | Lanseringsdatum | Önskat datum + ev. hårda deadlines |
| B12 | Budget | Tema (0–~3500 kr), appar (månadskostnad), översättning, domän |
| B13 | Betalningsleverantörer | Shopify Payments? Klarna? Vipps/MobilePay beroende på marknad? (aktivering = ditt ansvar) |
| B14 | Företagsuppgifter för nya marknaden | Juridiskt namn, org.nr, adress, momsregistrering (OSS/lokal) — krävs i policyer och sidfot |

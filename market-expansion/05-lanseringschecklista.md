# 5. Lanseringschecklista

Allt ska vara ✅ innan publicering. Publicering sker endast på ditt uttryckliga OK.

## Katalog
- [ ] Alla produkter i beslutat sortiment finns, med målspråkets titel + beskrivning
- [ ] Inga legacy-produkter/vendors med av misstag (Bäverkoppling, matstrumpor, superkoppling)
- [ ] Alla varianter har pris, SKU enligt ny struktur, konsekventa variantnamn
- [ ] Compare-at-priser korrekta och tillåtna (ingen fejkad rea) `[JURIDISK GRANSKNING]`
- [ ] Lagerpolicy beslutad (spårning av/på; inga negativa saldon; inga aktiva 0-lagerprodukter som inte får översäljas)
- [ ] Alla produkter har bilder + alt-texter; inga leverantörsvattenmärken
- [ ] Presentkort: en (1) korrekt konfigurerad, eller inget alls

## Struktur & innehåll
- [ ] Kollektioner med namn, beskrivning, bild; alla aktiva produkter tillhör minst en
- [ ] Huvudmeny: kategorier + Alla produkter + Om oss + Kontakt/FAQ
- [ ] Sidfot: policyer, kontakt, korrekt supportmail (rätt domän!)
- [ ] Startsida: hero, kategoriingångar, bästsäljare, förtroendesignaler
- [ ] Om oss, FAQ, leveransinformation, kontaktsida finns på målspråket
- [ ] Inga oanvända utkastsidor publicerade; inga svenska textrester på målspråkssidor

## Juridik & policyer
- [ ] Integritetspolicy, köpvillkor, retur/ånger, fraktpolicy — anpassade, utan mallvariabler
- [ ] En källa per policy (ingen motstridig dubblering sida vs Shopify-policy)
- [ ] Ångerrätt ≥ 14 dagar (EU), returadress + process beskriven
- [ ] Företagsuppgifter (namn, org.nr, adress, mail) i sidfot/villkor
- [ ] Cookie-/samtyckesbanner enligt målmarknadens krav
- [ ] Produktpåståenden granskade; extern juridisk slutgranskning gjord (**ditt ansvar**)

## Inställningar
- [ ] Marknad/språk/valuta korrekt; priser visas inkl. moms
- [ ] Skatteinställningar för målmarknaden (moms, OSS om EU-gränsöverskridande)
- [ ] Fraktzoner, priser, fraktfrigräns enligt beslut; leveranstider ärliga mot faktisk sourcing
- [ ] Betalning aktiverad och testad (**ditt konto**), rätt betalmetoder för marknaden
- [ ] Ordermail/notiser på målspråket, avsändaradress korrekt
- [ ] Domän kopplad, SSL aktivt, www/rot-redirect korrekt

## Kundresa & teknik
- [ ] Testorder hela vägen (mobil + desktop): produkt → kassa → ordermail → ev. återbetalning
- [ ] Inga brutna länkar/404 i menyer, sidfot, startsida, policylänkar
- [ ] Sidhastighet rimlig; bilder komprimerade
- [ ] SEO-grunder: sidtitlar, metabeskrivningar, alt-texter på målspråket
- [ ] Analys/pixlar (om beslutat) installerade och samtyckesstyrda
- [ ] Favicon, butiksnamn, sociala länkar korrekta

## Lansering
- [ ] Färsk backup/export tagen samma dag
- [ ] Ditt skriftliga GO
- [ ] Lösenordsskydd av / tema publicerat
- [ ] Efterkontroll 24–48 h: ordrar, mail, betalningar, felloggar

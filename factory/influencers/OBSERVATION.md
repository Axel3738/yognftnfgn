# Two-week story check — one profile, 2 minutes a day

For whoever follows the shortlist (Axel or the VA). English on purpose so the
VA can run it. Method: `factory/influencers/METOD.md` → section 4.

**Why:** in the method this check is 70 % of the decision. Numbers are the
other 30 %. One day tells you nothing — we need 14 days in a row.

## Every day, per profile (open their Instagram stories, then TikTok/YouTube)

Tick a box only if you saw it **today**.

| # | Question | Yes / No |
|---|---|---|
| 1 | Did they post stories today? | |
| 2 | Did they **talk to the camera** (face + voice, speaking to followers)? | |
| 3 | Was it personal — family, a problem, a bad day, everyday RV life? | |
| 4 | Was it warm and calm (no fighting, no drama, no politics)? | |
| 5 | Was there an ad/sponsored story today? (Yes = count it) | |
| 6 | Did they show their RV (inside, outside, parked, stored)? | |

## Once, on day 1

- Last 6 feed posts: write down the number of comments on each. Average under
  60 = weak signal.
- Read 20 comments. Strong = long personal replies, own stories, questions
  asking for advice. Weak = emojis, "love this", "goals".
- Where do they live, and do they store the RV in winter (snow, rain)?

## After 14 days — the verdict

| Result | Verdict |
|---|---|
| Talked to camera on 10+ of 14 days, personal, warm, ads on ≤ 3 days | **Gold** — reach out |
| Talked to camera on 5–9 days | Maybe — reach out if the list is short |
| Talked to camera on fewer than 5 days, or ads most days | **No** |

Write the result in the `Observation` column of
`factory/influencers/carashell-us/kandidater.md`: e.g. `11/14 camera, 2 ads — gold`.
Never write a result for days you did not check.

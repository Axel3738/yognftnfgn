# UGC outreach kit — start here

A small, standalone kit. It does **not** need Axel's repo, keys or accounts.
You need: a Claude account, a Google account, and this folder.

| File | What it is |
|---|---|
| `SOP.md` | **Your job, step by step, and what to do in every case.** Read it first. |
| `TERMS.md` | Prices and terms — the only numbers you may offer |
| `VETTING.md` | How to tell a good creator (7-question filter + score 0–16) |
| `SHEET.md` | How to set up and fill the Google Sheet |
| `TEMPLATES.md` | Every message, Swedish + English meaning |
| `CLAUDE.md` | Instructions for Claude (you don't need to read it) |
| `creators-sheet-template.csv`, `deals-sheet-template.csv` | Columns for the sheet |

## Setup (once, 15 minutes)

### Option A — claude.ai Project (easiest, nothing to install) ✅ recommended
1. Go to claude.ai → **Projects** → **Create project** → name it "UGC outreach".
2. **Set project instructions** → paste the whole content of `CLAUDE.md`.
3. **Project knowledge** → upload `SOP.md`, `TERMS.md`, `VETTING.md`, `SHEET.md`, `TEMPLATES.md`.
4. Make sure **web search** is on (the tools button in the chat box).
5. Start a new chat in the project and write a product link — or
   `reply <creator> <their message>`, `brief …`, `deal …`, `check …`.

Tip: use **one chat per creator** for replies, so Claude remembers the conversation.

### Option B — Claude Code (if you prefer the `/ugc` command)
1. Put this folder on your computer (or in your own GitHub repo).
2. Open it in Claude Code (desktop app or terminal).
3. Type `/ugc <product link>`.

### The Google Sheet
Follow `SHEET.md` → import the two CSV files → share the sheet with Axel.

### Drive
Create a Google Drive folder **"UGC deliveries"**, share it with Axel (edit).
One subfolder per deal.

## Your first day
1. Read `SOP.md` once, top to bottom.
2. Ask Axel which product to start with (he sends you the product link).
3. Paste the link into Claude → vet the creators → save them in the sheet →
   send the first 5 messages.

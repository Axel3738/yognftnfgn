# The Google Sheet — how to set it up and fill it in

One Google Sheet: **"UGC Creators — Bäverbutiken"**. Share it with Axel (edit).
It is our creator bank. We keep it for years, so keep it clean.

Import `creators-sheet-template.csv` and `deals-sheet-template.csv`
(File → Import → Upload → "Insert new sheet(s)") to get the columns, then name
the tabs **Creators** and **Deals**. Add a third tab **Avatars** by hand.

## Three tabs

| Tab | What goes in it |
|---|---|
| **Creators** | Every creator worth remembering — one row per person, forever |
| **Deals** | One row per deal (one creator can have many deals, one per product) |
| **Avatars** | The list of avatar tags we use (so everyone spells them the same) |

## Who gets a row in "Creators"

**Only creators that passed the quick filter** (`VETTING.md` §1). Not everyone
you looked at. Two kinds:

- **A — Use now:** 12+ points, fits the product you are working on. Contact them.
- **B — Future bank:** good, but not right for this product. Example: a
  60-year-old man with a boat who films well — perfect for a boat product next
  month. Save them. Do not contact yet.

Below 8 points or any red flag → no row.

## Columns in "Creators"

| Column | How to fill it |
|---|---|
| ID | C001, C002 … never reuse a number |
| Photo | Screenshot their profile picture → click the cell → Insert → Image → **Image in cell**. (Do NOT paste an image link — Instagram/TikTok links expire and the picture disappears.) |
| Name / handle | As written on their profile |
| Gender | M / F |
| Age range | 18–25 / 26–35 / 36–50 / 51–65 / 65+ (your best guess from the videos) |
| Region | City or region if visible, else "Sweden" |
| Avatar tags | From the Avatars tab, comma-separated. Example: `boat owner, dad, outdoors` |
| Settings they can film | Where their videos happen: garden, boat, car, kitchen, forest, beach, workshop … |
| Platform | TikTok / Instagram / Collabstr / Sprww / other |
| Profile link | Full link |
| Contact route | The PUBLIC route: bio email, platform chat, contact form |
| Email | Only if it is public on their profile |
| Score (0–16) | From `VETTING.md` §4 |
| Tier | A (use now) / B (future bank) |
| Their price | What they asked, e.g. "2 500 kr/video" — or "unknown" |
| Long-term? | Yes / No / Unknown — did they say yes to working on several products |
| Status | See the list below |
| Last contact | Date (YYYY-MM-DD) |
| Next action + date | One line: "follow-up 2026-10-02" |
| Notes | Anything useful: "fast replies", "has F-skatt", "great hands close-ups" |

**Status values (use exactly these words):**
`saved` · `contacted` · `follow-up sent` · `negotiating` · `deal` ·
`working` · `delivered` · `approved` · `paid` · `no reply` · `declined` ·
`too expensive` · `do not use`

## Columns in "Deals"

| Column | How to fill it |
|---|---|
| Deal ID | D001 … |
| Creator ID | From Creators (C001) |
| Product | Name + product link |
| Price per video | Agreed number |
| Videos | Number agreed |
| Total | Price × videos |
| Agreed date | Date the creator said "yes" in writing |
| Shopify order no. | The 0 kr order you created to send the product |
| Product arrived | Date |
| Videos due | Arrived + agreed days |
| Delivered | Date |
| Raw footage received | Yes / No |
| Approved | Date + who approved |
| Invoice received | Date |
| Sent to Axel | Date |
| Paid | Date (Axel tells you) |
| Result | Fill in later: "good — use again" / "ok" / "bad — do not use" |

**Never** put home addresses, phone numbers or personal ID numbers in the sheet.
They live in the Shopify order and in the chat only.

## The Avatars tab

Start with these and add new ones when a product needs them:
`dad`, `mom`, `grandparent`, `young man`, `young woman`, `boat owner`,
`caravan / motorhome`, `garden`, `dog owner`, `cat owner`, `fishing`,
`hiking / outdoors`, `car / DIY`, `handyman`, `farmer / countryside`,
`home & cleaning`, `beach / summer`, `winter`.

## Before contacting anyone

Search the sheet (Ctrl+F) for the name and the profile link. Found → do not
start a new conversation; continue the old one from its status.

# /ugc – UGC outreach

Argument: `$ARGUMENTS`

Follow `CLAUDE.md` in this folder exactly. Pick the mode from the argument:

- a product link → **find creators**
- `reply <creator> <their message>` → **reply**
- `brief <product link> <creator>` → **brief**
- `deal <creator> <price> <videos>` → **deal**
- `check <creator>` → **delivery check**

Read `SOP.md`, `TERMS.md`, `VETTING.md`, `SHEET.md` and `TEMPLATES.md` before
you answer. End with the VA's next actions, numbered.

## DEFINITION OF DONE
- [ ] Every Swedish message has its English meaning under it
- [ ] Nothing offered outside `TERMS.md`
- [ ] New creators given as tab-separated sheet rows
- [ ] The SOP case named (reply mode) and the new sheet status given
- [ ] No address / phone / ID number in any sheet row
- [ ] The VA's next actions last, numbered

# Store Launch Checklist — HeimGuard (manual steps)

Do the steps in order, top to bottom. Tick each one.
Everything not on this list is done by Claude Code.

* STORE NAME: **HeimGuard**
* DOMAIN: **heimguard.se**
* STORE EMAIL: **hej@heimguard.se**
* FORWARD TO: **subscriptions@stonebite.org**

## 1. Domain (Loopia)
- [ ] Log in to Loopia
- [ ] Buy **heimguard.se** – registrant must be the company, not you
- [ ] Domain → Email → Forwarding → create **hej@heimguard.se** → forward to **subscriptions@stonebite.org**
- [ ] Send a test email to **hej@heimguard.se** – confirm it arrives

## 2. Shopify – basics
- [ ] Settings → General → Store name → **HeimGuard** → Save
- [ ] Settings → Domains → Connect existing domain → **heimguard.se** → follow the DNS steps → Set as primary
- [ ] Settings → Languages → make **Swedish** default
- [ ] Settings → Notifications → Sender email → **hej@heimguard.se** → Save → click the verification link in the inbox

## 3. Shopify – payments
- [ ] Settings → Payments → Activate **Shopify Payments** → org number, bank, ID check
- [ ] Same page → **Klarna** → tick → Save
- [ ] Settings → Checkout → Customize → Logo → upload → Save

## 4. Judge.me
- [ ] Apps → search "Judge.me" → Install (free plan)
- [ ] Judge.me → Settings → Language → **Swedish**
- [ ] Judge.me → Settings → Review Widget → star color: **00B77F**
- [ ] Judge.me → Settings → Integrations → copy **API Token** → paste it into Claude Code when asked (never in chat or email)

## 5. Meta
- [ ] business.facebook.com → Pages → Create page: **HeimGuard**
- [ ] Ad accounts → choose account → Payment settings → add card (owner's card)
- [ ] Copy **Page ID** + **Ad account ID** → give to Claude Code

## 6. Discord
- [ ] Discord → + → Create server: **HeimGuard**
- [ ] Open the invite link Claude Code gives you → **Authorize** the bot

## 7. Hand over
- [ ] Tell Claude Code: **"Store ready: HeimGuard"** – it publishes the theme, creates the pixel, renames the ad account, builds Discord channels and imports reviews
- [ ] Owner changes the Loopia password afterwards

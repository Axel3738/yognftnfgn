# SOP: Return address and return instructions

**Use this when** the owner has approved a return and the customer needs to know
where to send it. Approval comes first — see "Customer wants to return product".

**Owner approval:** already given at this point. Sending the address is not a new
decision.

---

## 1. Before you write

| Check | Why it matters |
|---|---|
| The return was approved | The address is never sent on a guess |
| The return window (Store facts) | It runs **from the day the customer received the item**, not from the order date. With weeks of transit that is a completely different date — a case was judged wrong on exactly this |
| Who pays the return postage (Store facts) | The customer asks in the next email if you do not say it |
| The item is one we take back | Sale items, gift cards, perishables and personalised products are not returnable |

**The return address is not published anywhere on the site** (on stores where Store
facts says so). It is given out by support, on request. That is deliberate, and it
only works if the reply goes out fast — a customer who asks how to return and hears
nothing files a dispute instead, and a dispute costs more than the return.

---

## 2. The return instructions email

Take the address from **Store facts**. Fill the bracketed values.

> Hej [NAMN]! Din retur för order [ORDERNUMMER] är godkänd.
>
> Skicka paketet till:
> [RETURADRESS UR STORE FACTS]
>
> Tre saker gör att returen går igenom direkt:
> 1. Skriv **ordernumret** och **ditt fullständiga namn** synligt på paketets utsida.
> 2. Skicka med spårning och spara kvittot — det är ditt bevis på att paketet är på väg.
> 3. Varan ska vara oanvänd och i originalförpackningen.
>
> [Du står själv för returfrakten. / Vi betalar returfrakten.] Så snart paketet kommit
> fram och kontrollerats betalar vi tillbaka till samma betalsätt som du handlade med.
>
> Hör av dig om något är oklart!

*Meaning: your return is approved; here is the address; write the order number and
your full name on the outside; use tracked shipping and keep the receipt; item unused
in its original packaging; who pays the postage; refund to the original payment method
once it arrives and has been checked.*

Write in the customer's language (DeepL). **Never promise a number of days** for the
refund to show — that is their bank's.

---

## 3. Ask for the return tracking number

One line, and it saves the case later:

> Skicka gärna spårningsnumret på returen när du postat den, så kan jag följa den.

Without it, "I sent it back weeks ago" cannot be checked. Note the number on the
order so the next person sees it. A return parcel is **not** on our own tracking page
— look it up on the carrier's site or 17track.net.

---

## 4. Log it and close the loop

1. Write on the order: return approved, address sent, date, and the return tracking
   number when it arrives.
2. When the owner confirms the parcel arrived and was inspected, tell the customer the
   refund is done — do not wait for them to ask.
3. **If the parcel arrives without an order number or name**, do not tell the customer
   it will be thrown away. Ask the owner what they want to do; a parcel with no
   identification is an unhappy customer and a photo of the package usually solves it.

---

## 5. Definition of done

- [ ] Return was actually approved before the address went out.
- [ ] Return window counted from **delivery**, not from the order date.
- [ ] Address taken from Store facts — never typed from memory, never another store's.
- [ ] Email covers: address, order number and name on the outside, tracked shipping,
      unused in original packaging, who pays the postage, refund to the original
      payment method.
- [ ] Return tracking number asked for and noted on the order.
- [ ] Customer told when the refund is done.

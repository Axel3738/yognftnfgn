# Nathalie's script: give this to every new creator

**Axel 2026-10-01: "Jag ger gärna Nathalies manus till nya kreatörer — PÅMINN MIG BARA."**
So this is the standard script. Every new Matstrumpor creator gets it, word for word, as
video A (the copy). That is Evolve's recipe: one video copies the winner, one iterates on it,
one imitates a viral format (`docs/os/evolve/ITERATIONS-PLAYBOOK.md`, format-2;
`docs/os/CS-KLART.md` point 21).

Where the reminder lives (so it does not depend on anyone's memory):
- `/matstrumporkungen` step 6: every UGC order includes this file as video A.
- `products/matstrumpor/EVOLVE-PLAN.md`: the checklist Axel reads.

The winner is `09-17 Nathalie captions musik` (live since 2026-09-17, breakthrough). The only
change against the live ad: the end of the last line named the store and its web address.
Those words are struck, because the store's name never appears in an ad (Axel 2026-09-18).
Read off the captions on 2026-10-01; the first second has no words.

Spoken at a natural pace it runs about 35 seconds. The creator says every line on camera; the
editors burn the same words in as captions (max two lines) and add the music.

**Never:** the store's name or web address (also on packaging, labels and screens), prices,
offers, delivery times, guarantees, claims about material or quality. A reaction is never
faked or re-staged. The socks must be shown as socks within the first 10 seconds.

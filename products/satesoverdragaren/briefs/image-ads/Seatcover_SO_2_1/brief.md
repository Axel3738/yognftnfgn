# Seatcover_SO_2_1 — Cost-of-inaction static ("Vänta en säsong till?")

**Type:** New static (FAS 9) — risk / cost-of-inaction mechanism
**Format:** Static · 1:1 + 4:5
**Production level:** Simple
**Primary KPI:** CPA (target ≤ 281 kr, benchmarked against the offer static — same SO lane)

## Hypothesis
The offer static proves the money-frame converts (LPV→purchase 6.1%). This ad tests the same frame from the loss side: the cost of doing nothing (a ruined cushion → thousands for a new seat) versus 649 kr now. Loss aversion should qualify equally well and may out-close the discount frame without leaning on the sale. Variable vs SO_1_2: **gain-frame (rabatt) vs loss-frame (kostnad att vänta)** — layout family and lane (SO) held constant.

## Design brief
- Visual: cracked/worn bare seat photo as the dominant image (real frame from `PD_2` master inset — the orange-mower photo; no AI damage). Small inset bottom-right: the fitted grey/yellow cover (winner frame).
- Palette: match the account's grey/yellow; warning tone allowed on the compare row only.
- QA: word-for-word text; å/ä/ö; the only digits in the image are 649 and 30.

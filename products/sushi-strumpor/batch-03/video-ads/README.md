## Global rules

- **The box is in the first frame and the first reveal (roll → sock) happens before second 2.** No intro, no logo, no talking head, no faces.
- **Real product.** Order a box from matstrumpor.se if you do not have one.
- **Captions burnt in, Swedish word for word, max 2 lines, inside the middle 80 % of the frame.** Must work with the sound off.
- **Offer only in the fixed end card:** `matstrumpor.se · Köp 1 – Få 1` (042: `Köp 2 – Få 2`). No prices, no percentages, no size, no material claims, no Christmas.
- **Export 9:16 (1080×1920) + 4:5 crop (1080×1350).** H.264, ≤ 30 MB. File name = ad name.
- **Swedish VO by a native speaker, calm, ~2 words per second.** The buyer is 50+.
- **AI footage → Meta AI disclosure ON.** Report it.
- **Meta copy is constant for all five** (the proven primary text + headline) — the video is the only variable.

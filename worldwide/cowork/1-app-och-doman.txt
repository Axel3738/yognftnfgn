STEG 1 — hitta rätt app
------------------------------------------------------------------------------

1. Öppna https://dev.shopify.com → Apps. Leta efter "Bäver uppladdare".
2. Öppna den och gå till Settings (eller "Client credentials"). Kontrollera att
   Client ID börjar med c08d97a8.
3. Finns appen inte där: öppna butikens admin → Inställningar → Appar och
   försäljningskanaler → Utveckla appar → "Bäver uppladdare" → Konfiguration.
   Samma kontroll av Client ID / API-nyckel (börjar med c08d97a8).
4. Stämmer inte Client ID någonstans: STOPPA hela steg 1–2 och skriv vad du såg.
   Det kan finnas appar med liknande namn. Client ID avgör, inte namnet.

------------------------------------------------------------------------------
STEG 2 — lägg till rättigheterna
------------------------------------------------------------------------------

Om appen ligger i Dev Dashboard (dev.shopify.com):
1. Versions → Create a version (eller "New version").
2. Leta upp fältet Scopes (under Access). Det är en kommaseparerad lista.
3. INNAN du ändrar något: kopiera fältets innehåll ordagrant till rapporten under
   rubriken "FÖRE". Kontrollera att alla 12 ovan täcks.
   Är fältet TOMT eller saknas något: STOPPA. Skapa inte versionen. Ett tomt fält
   betyder att versionen inte utgår från den aktiva, och släpps den försvinner
   alla rättigheter.
4. Ställ markören SIST i fältet och skriv till, utan mellanslag:
     ,write_markets,write_translations,write_locales,write_shipping,read_legal_policies,read_online_store_navigation
5. Kopiera fältets nya innehåll till rapporten under "EFTER". EFTER ska vara
   FÖRE + raden ovan, inget mer och inget mindre.
6. Ändra inga andra fält. Döp versionen till "worldwide-2026-09-30" om den frågar.
7. Tryck Release. Kontrollera under Versions att den nya versionen är Active.

Om appen ligger under "Utveckla appar" i admin:
1. Konfiguration → Admin API-integration → Redigera.
2. Skriv i rapporten vilka rutor som är ikryssade FÖRE.
3. Kryssa i (bara kryssa i, aldrig ur): Markets (skriv + läs), Translations
   (skriv + läs), Locales (skriv + läs), Shipping (skriv + läs), Legal policies
   (läs), Online store navigation (läs).
4. Spara. Skriv i rapporten vilka rutor som är ikryssade EFTER.

STEG 5 — engelska texter i Kaching Bundles
------------------------------------------------------------------------------

Paketväljaren på produktsidorna (1 st / 2 st / 3 st) kommer från appen Kaching
Bundles och är på svenska. Kunder utomlands ska se engelska. Den svenska texten
får INTE ändras.

1. Admin → Appar → Kaching Bundles.
2. Leta efter översättningar: "Translations", "Languages" eller en
   språkväljare i varje erbjudande (deal). Läs appens egen hjälptext.
3. Finns engelska (English) att välja: lägg in de engelska texterna nedan på
   VARJE erbjudande som har de svenska texterna. Svenskan står kvar som den är.

   | Svenska (står kvar)                        | Engelska (läggs till)                    |
   |--------------------------------------------|------------------------------------------|
   | 14 Dagars Ångerrätt & Svensk kundsupport   | 14-day returns · Swedish customer support |
   | 1 st                                       | 1 pack                                   |
   | 2 st                                       | 2 pack                                   |
   | 3 st                                       | 3 pack                                   |
   | Standard pris                              | Standard price                           |
   | Mest populär                               | Most popular                             |
   | Spara (följt av belopp eller procent)      | Save                                     |
   | Gratis / GRATIS                            | Free / FREE                              |

   Andra svenska texter du hittar i ett erbjudande: översätt dem kort och rakt,
   aldrig med ett pris i kronor, och skriv dem i rapporten.
4. Finns ingen engelska att välja (appen visar bara språk som är tillagda i
   Shopify, och engelska läggs till av min session efter dig): gör ingenting mer
   i Kaching. Skriv exakt vad appen visade och var översättningarna ligger, så
   gör sessionen resten.
5. Spara. Publicera eller aktivera inga nya erbjudanden och ändra inga rabatter.

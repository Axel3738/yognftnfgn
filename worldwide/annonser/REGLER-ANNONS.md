# Rules: Bäverbutiken ads → English for Beaver Store (worldwide)

The Swedish ads below are Bäverbutiken's proven winners (ranked on profit). They go to a
worldwide English audience (US, UK, Canada, Australia, NZ, Ireland, Europe) and link to
beaverstoreco.com, where the store is called **Beaver Store — a Swedish brand**.

Read `docs/copy-regler.md` (the three-question test) before you write a line.

## Keep what won

- Same angle, same hook idea, same order of claims. You are translating a winner, not
  writing a new ad. Plain, concrete English; contractions are fine.
- Every line must pass the three-question test (visualize / falsify / nobody else can say
  it). Show the test for the headline and the first line of the primary text.

## Never carry these abroad

| In the Swedish ad | English |
|---|---|
| any price in kronor (`909 kr`, `299 KR`, `579 kronor`, `ord. 1 469 kr`, `Spara 273 kr`) | remove it. Prices differ per currency. A percentage (`40% off`, `23% OFF – TODAY`) may stay ONLY if the Swedish ad states that same percentage |
| `Klarna`, `betala med Klarna`, `få först, betala sen` | remove |
| `Fri frakt`, `Fri frakt inom Sverige` | `Free shipping` |
| `30 dagars öppet köp` / `nöjd-kund-garanti` | `14-day returns` (the store's return policy abroad is 14 days) |
| `14 dagars ångerrätt` | `14 days to change your mind` |
| fars dag, jul-deadlines, Swedish holidays and dates (`Beställ senast 19 oktober`) | the ad is skipped (write `"hoppa": "<reason>"`) |
| a quote credited to "Verifierad kund" / a named customer | the ad is skipped — those quotes cannot be verified for a new market |
| `Bäverbutiken`, a domain, a store name | never. Ads never name the store |
| Swedish climate/seasons (`svensk vinter`) | `Nordic winter` only if it matters; otherwise drop |

Metric units stay. `4 st` → `4-pack` or `set of 4`. `hk` → `hp`.

## The last line of every primary text

`A Swedish brand.` — alone on its own line. (Same principle as CaraShell and
Matstrumpor abroad: the Swedish origin is the trust signal, the store name is never used.)

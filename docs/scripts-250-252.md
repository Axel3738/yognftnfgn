## 250 — "Grillarna jag inte kunde rädda" (Investerings-VSL, 8–10 min, teknikern)
Struktur: cold open vid död grill (245-material återanvänds) → jobbet ingen pratar om
(utdömningarna, altansamtalen) → mönstret (ytan blank, springorna svarta) → mekanismen
(frätande fett, missfärgning→rost→spjälkning) → de noggranna som gör fel (frikännande)
→ avbränningsritualen (ärvd, funkar inte, kamado/packningen) → Weber-erkännandet →
incitamentsfrågan ("ingen i branschen förlorar på att gallret äter din grill — utom du")
→ mot-eget-intresse ("hälften så många kunder") → grillarna som överlever (upptäckten:
elektriska borsten på kroken) → Mastern + metoden (varmt galler, ånga, grov→polering)
→ matten (2000 kr/år värdetapp vs 999 en gång) → tillbaka till döda grillen → close
"Femton år eller sju. Det avgörs på sextio sekunder."
Hooks: H1 "Igår dömde jag ut en grill för arton tusen..." / H2 "samtalet jag hatar att
ta" / H3 "grillar går sällan sönder — de blir långsamt mördade av ett verktyg ägarna
litar på". Full copy i chatten 2026-07-30.

## 251 — "Septemberklockan" (säsong, 60–90 sek, teknikern) — LANSERAS AUGUSTI
Vinkel: investeringen, format: äkta deadline. Kärna: "Skillnaden avgjordes i september"
— fettet jobbar hela vintern under locket; vårens telefonsamtal som bevis; sista
rengöringen innan förvaring = säsongens viktigaste. Hooks: H1 "Din grill kommer skadas
mer i vinter än under hela sommaren" / H2 "vilka grillar som inte överlever vintern
syns redan i september" / H3 "säsongens viktigaste rengöring är den sista innan locket
går på". Full copy i chatten.

## 252 — "Studien" (JoFS-storyn, 60–90 sek, brandröst — NY BUDBÄRARE: vetenskapen)
Loggad idé från 101 B2-sessionen, nu inlöst. Vinkel: smaken (högst-CTR-territoriet).
34 %-studien som story: frågan ingen ställt → jämförelsen → siffran → mekanismen
(rök + hinna) → "gallret ser rent ut, skorpan sitter i springorna" → Mastern → "En
tredjedel av smaken sitter i gallret. Ta tillbaka den." Ingen persona = billigast att
producera. Hooks: H1 "studien nästan ingen läste" / H2 "mätt i procent: trettiofyra" /
H3 "siffran borde stå på varenda grill som säljs". Full copy i chatten.

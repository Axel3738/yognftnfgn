# Materialgaten (gate 4) + ekonomi (gate 5) — instruktion per granskningsagent

Du granskar LEVERANTÖRSMATERIALET för en lista Temu-kandidater som passerat gate 1–3. Temu-datan är redan hämtad: för varje goods-id finns `hunt/raw/<goods_id>.json` (titel, pris SEK, betyg, antal recensioner, recensionsdatum, bilder med variantbeskrivningar, video-URL) och — om listningen har video — `hunt/video/<goods_id>.mp4`. Rör INTE temu.com (blockerat). Ladda ner bilder från `img.kwcdn.com` med curl (det fungerar).

För varje kandidat:
1. **Frames:** `mkdir -p hunt/material/frames/<id>` och `ffmpeg -loglevel error -i hunt/video/<id>.mp4 -vf fps=2 -frames:v 8 hunt/material/frames/<id>/h_%02d.jpg` (0–3,5 s) + `ffmpeg -loglevel error -ss 6 -i … -frames:v 1 …/s06.jpg` + `-ss 12` + `-ss 20`. ÖPPNA alla med Read. Videolängd: `ffmpeg -i fil 2>&1 | grep Duration`.
2. **Hero + galleri:** ladda ner `images[0]` och två till, ÖPPNA dem. Läs `image_descriptions` (variantnamn!).
3. **Bedöm exakt (mallen i uppdraget):** vad händer sekund 0–3 · syns produkten i bruk inom 3 s · är det SAMMA fysiska produkt som listningens hero · inbränd utländsk text (var, hur mycket, går den att beskära) · tydlig handling och payoff · förstås mutad · objekt/ägare synlig · ren inramning · naturligt bruksbevis · kan råfilmen + svenska captions vara kärnannonsen (JA/NEJ/KANSKE) · heron ensam som annons (JA/NEJ). Resultat: **STRONG PASS / PASS / FAIL** + två meningar varför. Ingen video = bedöm heron/galleriet; sätt FAIL om varken video eller textfri kontexthero finns.
4. **Ekonomi (gate 5):** landad kostnad ≈ Temu-pris × 1,5 (uppskattning, kalibrerad på IBC 108,51→165 och motorhölje 71,22→116); tänkt svenskt pris = välj det pris som (a) ≥ 2,4 × landad, (b) ≥ 300 kr, (c) ligger under ev. märkesankare ur `hunt/hylla/*.json` (läs filen för konceptet om den finns); BE-CPA = pris − landad (≥ 190 krävs); flerköpsskäl; prisets läge mot 300-kronorsgränsen. Resultat PASS/FAIL + talen.
5. **Temu-signaler:** notera betyg, antal recensioner, recensionsdatum (senaste 30 dagarna = velocitet), antal bilder, video ja/nej — bara som data.
6. **Slutdom** per kandidat: tier A/B/C/ELIM med `structure_match` 0–100 (fingeravtrycket i docs/temu-vinnar-dna.md avsnitt 12: objekt, presens, hylla, material, pris, variant, hook, publik — väg material och presens tyngst), `category_novelty` 0–100, `biggest_risk`, `confidence`.

Leverans: JSON-array till angiven fil, ett objekt per goods-id: `{goods_id, concept, kluster, video_len_s, sec_0_3, product_in_use_by_3s, same_product_as_hero, burned_text, muted_ok, owner_or_object_visible, raw_plus_captions_viable, hero_alone_viable, material_result, material_reason, temu_price_sek, landed_est_sek, se_price_est_sek, multiple, be_cpa_est_sek, multibuy_reason, economics_result, rating, review_count, reviews_last_30d, image_count, has_video, tier, structure_match, category_novelty, biggest_risk, confidence}`. Hitta aldrig på ett värde. Sista chattsvaret: "klar: <fil>" + en rad per kandidat: id · material · ekonomi · tier.

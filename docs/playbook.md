# Playbook — bevisade vinnare

Destillatet av allt vi lärt oss. Medan `ad-tracker.md` är rådata per annons, är det
här **slutsatserna** som håller över flera tester: vilka angles, format och hooks som
konsekvent presterar för respektive brand.

Regel: en insikt får flytta in hit först när den bevisats i **minst 2 oberoende tester**
(inte en engångsträff).

## Vinnande angles (rankade på egen data)
1. **Auktoritet / story** — "Grilltekniker" (110) + "Farfar" (101). Mest spend totalt *och* högst CTR (4,8–6,6%). Den bärande vinkeln.
2. **Trust / anti-scam** — 049. **Högst ROAS i skala (2,47).** Svensk-specifik ("inte ett Rusta-fynd", "du får exakt vad du ser").
3. **Problem → smak** — 088 (ROAS 2,36). "Du skyller på köttet. Det var aldrig köttet."
4. **Skydda investeringen / förstör grillen** — 128 (~73k). "Inbränt fett är frätande." Pivoten, bevisad.
5. **Social proof / kundcitat** — 050 (ROAS 2,12).

## Vinnande hooks
- Högst CTR: **"Det är därför köttet smakar som det gör."** (101 H3, 5,7%) — smak > rent galler.
- Mest köpta: **"Jag har öppnat tusentals grillar..."** (110 H2).
- Story-öppningar (farfar, grilltekniker) stoppar scrollen bäst.

## Vinnande format
- Auktoritet funkar med **expert-foto + makrobild på smutsig springa**.
- Social proof funkar som **citat-kort**.
- Problem funkar som **before/after** på gallret.

## Vad som inte funkar (eller är förbrukat)
- **Säkerhet / borststrån i maten** som *huvudkrok* — mättad marknad efter recall-vågen. Lever kvar som *bevis-rad* (B4), inte hook.
- **"Tre anledningar" / ren mekanism** (145) — svagast ROAS (1,36). Nedprioritera.
- **Rabatt som huvudvinkel** — syns inte bland vinnarna; håll priset.

# Ad Tracker — live-dokumentet ("hjärnan")

Det här är dokumentet jag uppdaterar **live** vartefter vi bygger, testar och lär.
Varje annons vi skapar hamnar här: namnet, hypotesen, vem som trodde på den och
varför, vad datan sa, och vad vi lärde oss.

> Legend — **Status:** 📝 draft · 🟢 live · ⏸️ paused · 💀 killed · 🚀 scaling
> **Tro:** vem drev idén — 🤖 Claude · 🧑 Du · 🤝 båda

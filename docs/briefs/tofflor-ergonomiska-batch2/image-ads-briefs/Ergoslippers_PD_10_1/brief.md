## WHAT THIS AD IS

A photo of bare feet on a hard floor with a headline about the pain you only
notice in the evening. One mechanism line explains why, the footer offers the fix.
It tests the pain angle properly in static form.


## Concept (for the pipeline/AI)

RISK / COST-OF-INACTION built on the landing page's strongest line ("Det märks
inte direkt. Det märks på kvällen."). Same pain territory as the campaign's
highest-CTR signal (`ONDA FÖTTER?`, 4.65 % — too little data for a verdict; this
tests it properly). Hypothesis: delayed-consequence copy out-converts direct
product claims.

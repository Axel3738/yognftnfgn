# Video ads — Ergoslippers batch #2 (Tofflor Ergonomiska, Bäverbutiken)

7 video briefs. Each folder is self-contained: an editor should be able to work from the
brief alone. Read this page first, then your assigned brief.

## Global rules (apply to every video)

1. **Price is 309 kr.** Compare-at price 400 kr (shown struck-through), "spara 91 kr".
   NO other numbers, no percentages, no discount codes. If any source file shows another
   price, do not use that frame.
2. **The product must be on screen before second 1** — the slippers or the orange insole.
   NEVER open on packaging, shipping bags or boxes (that exact mistake cost 565 SEK with
   0 sales in batch #1).
3. **Swedish captions word-for-word from the brief.** White rounded caption box, black
   text, one short line at a time, centered lower third (keep inside the middle 80 % —
   Reels UI covers top/bottom). Do not translate, do not "improve", do not add emojis.
4. **Must work with sound off.** Captions carry the message. Music optional, no voiceover
   unless the brief includes VO lines.
5. **Length 12–25 s.** Export **9:16 (1080×1920)** and **4:5 (1080×1350)**.
6. **No AI-generated humans.** Real hands/feet footage only. If a required shot is
   missing, STOP and request it — do not substitute with AI.
7. **Product print warning:** the shoe carries garbled English print ("Reality Summer
   Adevnutres New Day"). Frame close-ups so the print is not readable.
8. **No fabricated reviews, star ratings or "verified customer" claims. No medical
   claims** (no diagnoses). The ceiling is the product-page language: "avlastar leder
   och rygg", "som att gå på moln".
9. **Spelling traps (Swedish):** "tofflor" (never "tofflar"), "stötdämpande",
   "halkfria", "öppet köp", "jämförpris". Copy the caption table exactly — it is final.
10. **End card on every video:** product shot + "309 kr" + struck-through "400 kr" +
    "30 dagars öppet köp" + button text from the brief.

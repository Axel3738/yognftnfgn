# MATSTRUMP_sushi_curiosity_slideshow_serutsommat_v1

**Ad name:** MATSTRUMP_sushi_curiosity_slideshow_serutsommat_v1
**Concept:** A photo-dump slideshow that opens on a sushi-vs-sock-sushi mix-up gag, then rides that same "wait, is that real?" curiosity through everyday gifting moments before revealing the box itself is the gift wrap.
**Target audience:** Swedish gift-buyers (parents and grandparents, ~30–65) picking a fun, low-stakes gift for a teen or young adult — birthdays or no-reason gifting — who scroll past anything that looks like a normal ad.

### Format specs
- 4:5 (1080×1350) primary feed placement + 9:16 (1080×1920) safe-crop version for Stories/Reels.
- 7 stills (within the 6–8 range), hard cuts only — a simple crossfade is fine on one or two if it feels better, never a wipe/zoom/spin/animated transition.
- 1.5–2.5 s per slide, see table for exact timing per slide.
- Calm, trending-reel-style background track — soft acoustic/lo-fi/piano type. Editor's pick, must be license-safe/royalty-free for Meta ads. No voiceover, no talking head, no sound effects.
- Overlay style: simple white/off-white text, plain sans-serif, subtle shadow or soft scrim strip behind it for legibility. No boxed lower-third graphics, no logo bug — nothing that reads as a template ad. Keep text upper- or lower-third, never over faces or the detail that makes the joke land. Same treatment on every slide.
- 9:16 crop note: these stills aren't shot for vertical. Don't crop tight into the 4:5 frame — pad top/bottom with a blurred, zoomed duplicate of the same still (or a soft neutral blur) so nothing is lost, and keep all text inside the middle ~80% of the frame height so Meta's UI doesn't sit on top of it.
- Files live in `theme-matstrumpor/ugc-bilder/bilder/`.
- File naming for delivery: `MATSTRUMP_sushi_curiosity_slideshow_serutsommat_v1_4x5.mp4` and `MATSTRUMP_sushi_curiosity_slideshow_serutsommat_v1_9x16.mp4`.
- Order note: brief suggested picking either 15_bilen or 14_korsord — using both instead, to stretch the middle of the arc across two different life stages (younger/parent-aged pickup, older/retired at-home) without adding a new image.

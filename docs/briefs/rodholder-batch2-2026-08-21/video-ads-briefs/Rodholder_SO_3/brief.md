# Rodholder_SO_3_H1 — "72 kr per hållare" (true value, no fake discount)

**Type:** Video · **Production level:** low (supplier/demo footage + captions) · **Tier 2**

## Hypothesis

The old discount concept (40 % off) performed at demo-level CPA (143.80 kr) but its claim was false and has been retired. Hypothesis: an honest price-mechanic hook (289 kr ÷ 4 = ~72 kr per clamp) keeps the offer-audience conversion without the legal/trust problem. Isolated variable: **offer framing** (per-unit value vs no offer vs [retired] fake discount).

## Format & structure

9:16 + 4:5, 12–18 s, works muted.

| Beat | Time | Visual |
|---|---|---|
| HOOK | 0–3 s | All 4 clamps in hand / laid out; big caption with the per-unit price |
| VALUE | 3–7 s | One clamp clicked on a rod — "this is what 72 kr does" |
| DEMO | 7–12 s | Quick cuts: boat use + wall use |
| TRUST | 12–15 s | Guarantee + Klarna caption |
| CTA | 15–18 s | 289 kr / 4-pack end frame |

Creator: none, hands only, real footage. Editing: the per-unit price line is the hero — biggest text in the video. **Never write any discount, percentage, or "before" price.** If free shipping is mentioned it must read exactly `Fri frakt över 300 kr`. CTA: SHOP NOW.

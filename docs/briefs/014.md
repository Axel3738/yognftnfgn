## The dual-track rule (the whole point of this ad — do not merge the tracks)

- **VOICEOVER** = buy-signal + scarcity + practical arguments.
- **ON-SCREEN TEXT** = curiosity + the joke. Different words, different job.
- Never put the same line in both tracks. Silent scrollers get the joke; listeners get the urgency.

**Type:** Static, 3-block trust-stack (quote → product → guarantee badges),
format transfer of SP_2_1's proven quote-card structure.
**Hypothesis:** SP_2_1 (single quote + product + CTA) is untested in isolation
(0 purchases, 4,28 kr spend — CBO-starved, not proven or disproven) but shares
its copy with the account's only proven ad. Stacking the SAME real quote with
two additional REAL trust facts (guarantee + fabric spec) instead of the CTA
button alone should raise perceived credibility without inventing a second
fake review. **We do NOT fabricate a second customer quote** — CLAUDE.md
rule 3 forbids inventing kundinsikter, so this test isolates layout density
(one proof point vs. three), not proof quantity via fake reviews.
**Isolated variable:** number of real trust signals stacked (1 → 3), same
quote, same product shot type.
**Kept:** the exact testimonial line, product-on-real-tap photography style.
**Changed:** layout adds two more real, verifiable trust badges below the
product (guarantee + fabric spec) instead of a single CTA button.

## Why this ad exists (from the 2026-08-29 teardown)
SP_1_H3 (video) proves the testimonial angle converts. SP_2_1 (static, same
quote) never got real spend to prove or disprove the static execution. Rather
than just resubmit the same static, this version tests whether stacking real
proof (quote + guarantee + spec) beats a single quote — a legitimate
format-transfer test that doesn't require a second fabricated review.

## Design brief
- Top third: the real customer quote in a clean quote-card (same visual
  treatment as SP_2_1 — light blue sky gradient background, dark text).
- Middle: product mounted on a real outdoor tap, snow visible (reuse existing
  Kranskydd product photography — the Shopify studio + lifestyle shots, or
  the existing SP_2_1 image if the license/rights allow reuse).
- Bottom: TWO badges side by side, not one CTA alone —
  "30 dagars öppet köp" and "420D Oxford-tyg" — then the CTA button below
  both, not instead of them.
- Keep total on-image text under the account's existing density (SP_2_1 is
  the ceiling — do not add more words than that ad already has).

baseline yet, so this is really the first real read on the static

whether stacking real trust signals (vs. a bare quote) lifts conversion — a
reusable finding for every other product's testimonial statics.
